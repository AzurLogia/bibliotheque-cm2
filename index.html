Ajouter un outil

Copie d’abord le fichier dans le dossier de la matière, puis saisis son chemin ici. Le navigateur ne peut pas déplacer automatiquement le fichier.

Comment utiliser la bibliothèque ?

  1. Ouvre index.html dans Chrome, Edge ou Firefox, après avoir extrait complètement le ZIP.
  2. Choisis une matière ou utilise la recherche, puis clique sur Ouvrir l’activité.
  3. Pour ajouter une activité, place son fichier .html dans le dossier de la matière (par exemple Francais/), puis clique sur ＋ Ajouter et indique le chemin relatif, par exemple Francais/ma_nouvelle_activite.html.
  4. Les ajouts sont mémorisés sur cet ordinateur tant que le navigateur le permet. Pour conserver et déplacer durablement tes modifications, clique sur Exporter l’index. Remplace alors le fichier index.html du dossier principal par le fichier téléchargé, après l’avoir renommé index.html.
À savoir : le portail référence les fichiers, mais ne les copie pas lui-même. Pour passer la bibliothèque sur une clé USB, copie tout le dossier, avec ses sous-dossiers. Les anciens fichiers restent consultables en cochant « Afficher les anciennes versions ».
